Install certificate

Installing this server's certificate on your device once makes the browser stop showing the certificate warning and lets you install this app (PWA). The server is your own machine, and the certificate stays trusted even when the server restarts or its IP changes.

Android
  1. Tap Download certificate above, then open the downloaded file (tap the download notification, or open it from the Downloads app).
  2. Android's certificate installer opens. If asked for the certificate type, choose CA certificate, then confirm with Install anyway. The warning about network monitoring is standard for every user-installed CA.
  3. If the file does not open the installer automatically, go to Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate, and pick the downloaded file.
  4. Fully close your browser (swipe it away in Recent Apps), reopen this page, and tap “Reload page” below — the warning should be gone.
  5. You can now use the browser menu → “Install app” / “Add to Home screen” to install this as an app.
iPhone / iPad
  1. Tap Download certificate in Safari and allow the configuration profile download.
  2. Open Settings — “Profile Downloaded” appears at the top of the main list. Tap it → Install → enter your device PIN → Install.
  3. This step is easily missed: go to Settings → General → About → Certificate Trust Settings and switch on full trust for “inara Local CA”.
  4. Fully close Safari (swipe it away from the app switcher), reopen this page, and tap “Reload page” below — the warning should be gone. Open the page via one of the IP addresses the server prints in its log; other hostnames are not covered by the certificate.
Desktop
  1. Tap Download certificate, then import the file into your OS or browser trust store (macOS: Keychain Access → System → set to Always Trust; Windows: Install Certificate → Trusted Root Certification Authorities; Linux: system CA store or browser settings).
  2. Restart the browser and reload this page.
